## What was not run, and why

- **End-to-end wasm-host rustc run**: not rerun in this submission. The
  existing stage-C results (`../../../../docs/results.md`,
  `../../../../docs/compiler.md`) record a
  rustc.wasm built from `b6eeb93` + the patch series, run under Wasmtime
  50.0.2 with plain WASI p1, importing no `wasi:thread-spawn` and evaluating
  the plugin correctly. That run needs the full rustc.wasm build and a
  Wasmtime host, which is outside this patch-preparation time/disk budget.
- **A new in-tree rustc test**: none added. Normal rust CI does not build a
  wasm-host rustc; a regression test would need a new wasm32-wasip1-host CI
  job. This is called out in the PR body as the main test gap.
- **`wasm32-wasip1-threads` build**: not run. The patch's
  `cfg(target_arch = "wasm32")` would also apply there; the PR body records
  this as a review question.
